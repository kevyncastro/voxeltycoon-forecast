# Security policy

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue:

1. Go to the [Security tab](https://github.com/kevyncastro/voxeltycoon-forecast/security) of this repository.
2. Click **Report a vulnerability**.

Include what you found, how to reproduce it, and which version of the mod you used.
You'll get a reply as soon as possible, and a fix will be released before details are made public.

## Scope

Voxel Forecast runs inside Voxel Tycoon. It reads game data and stores its own history inside your savegame.
It does not connect to the internet or read files outside the game.

Examples of things worth reporting:

- a savegame crafted to make the mod crash the game or misbehave when loaded
- anything that lets the mod affect files or data outside the game

Problems in Voxel Tycoon itself should go to the game's developers.

## Supported versions

Only the latest version on the Steam Workshop receives fixes.
